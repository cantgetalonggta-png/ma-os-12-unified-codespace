# Open the Unified Codespace

Repo: https://github.com/cantgetalonggta-png/ma-os-12-unified-codespace

## UI (recommended)
1. Open the repo on GitHub.
2. **Code → Codespaces → Create codespace on `main`**.
3. Wait for devcontainer build.
4. Terminal: `bash scripts/bootstrap.sh && bash scripts/status.sh`.

## CLI
```bash
gh codespace create -R cantgetalonggta-png/ma-os-12-unified-codespace -b main
```

> Agent note (2026-09-27): `gh codespace create` returned *you cannot create codespaces with that repository* from this environment — usually means Codespaces billing/plan or org policy on the account. Use the GitHub UI button (no extra approval needed if Codespaces is enabled for your user).
